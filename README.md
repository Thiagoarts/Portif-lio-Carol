🌸 Portfólio - Carol

Este projeto é um site de portfólio desenvolvido para uma fotógrafa, com o objetivo de apresentar seus trabalhos e facilitar o contato com clientes interessados em seus serviços.

A página foi criada para ser simples, visualmente agradável e fácil de navegar, permitindo que visitantes conheçam o trabalho da profissional e entrem em contato rapidamente.

🚀 Tecnologias utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

HTML5 → estrutura da página

CSS3 → estilização e layout

JavaScript → interatividade

Git & GitHub → versionamento do projeto

🎯 Objetivo do projeto

O objetivo deste site é:

Apresentar o portfólio da fotógrafa

Divulgar seus trabalhos de forma profissional

Facilitar o contato de clientes interessados

Criar uma presença online acessível

📸 Funcionalidades

O site possui:

Página inicial com apresentação

Seção About / Sobre

Exibição de habilidades e projetos

Área de contato

Layout moderno e responsivo
